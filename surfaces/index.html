How to read it

A surface is a page, not a place. The model holds the MCP server and the chat, not the host that serves them or the domain they answer on. What it describes is what a visitor or an agent reads.

Written or built says where the rules are kept. A written surface keeps its projection rules in the model, because nothing re-runs a person. A built surface names the repository whose build writes it, and the rules are that build.

No line is typed. Each surface sits under the maker its own file names, so the drawing cannot disagree with the model.

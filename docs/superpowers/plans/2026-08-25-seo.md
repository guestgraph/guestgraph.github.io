# SEO — plan

*Spec: `docs/superpowers/specs/2026-08-25-seo-design.md`.*

## 1. The checks, first

Port `seo` from `blust.ch`'s suite and set `seo: true` on all five pages. Add the crawl-map
block this suite never had — sitemap URLs resolve, and every `Sitemap:` line in
`robots.txt` resolves. Run it. **Both must fail**: `seo` on four pages, and `robots.txt` on
the two 404s. Shown, not assumed — the robots assertion was re-run with the bad line put
back, and it named it.

## 2. robots.txt

Drop `sitemap-site.xml` and `talks/sitemap.xml`. Correct the comment that says the talks
repository owns those URLs; it doesn't, they live here now.

## 3. Structured data, rebuilt so it resolves

Every page carries `Organization`, `WebSite`, its own `WebPage`, and — where nested — a
`BreadcrumbList`. The landing page adds `SoftwareSourceCode` with the repository and the
Apache-2.0 licence, both verified against the GitHub API rather than copied from the prose.

## 4. The head contract

`/talks/`'s canonical becomes absolute. `og:locale:alternate` = `de_CH` on the three pages
missing it; `/talks/` and `/talks/intro/` already had it.

## 5. Re-render the cards

Every page's markup moved, so every card is stale by the recipe's design. `npm run og`,
commit `og.png` and `og.sha` together.

## 6. Verify

`npm run test:og`, `npm run og:check`, then the browser suite against a served copy.
